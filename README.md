# Spotting Export – v1.1
Lightroom Classic → Photoshop → ready-to-post Instagram carousel – with one keyboard shortcut. Runs 100 % locally.
Von Lightroom Classic zum fertigen Instagram-Carousel – mit einem Tastenkürzel. Läuft komplett lokal.

**Download:** [English](../../releases/latest/download/Spotting-Export-EN.zip) · [Deutsch](../../releases/latest/download/Spotting-Export-DE.zip)

## Requirements · Voraussetzungen
- macOS with Adobe Lightroom Classic + Adobe Photoshop (tested with Photoshop 2026)
- No Shortcuts app, no AI, no internet, no subscription · Keine Kurzbefehle-App, keine KI, kein Internet, kein Abo

## Install · Installation
Unzip → `bash install.sh` in Terminal → assign a keyboard shortcut in Photoshop (File → Scripts → Spotting-Export).
Setup & usage guides (EN/DE) are inside each package · Anleitungen liegen in jedem Paket.
